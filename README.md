# 🏦 Bank Account Simulation System in Java

A console-based banking application developed in Java as part of the **Java Programming Virtual Internship** at **CodeOrbit Tech** (Batch IND1).

---

## 📌 Project Overview
The **Bank Account Simulation System** mimics real-world core banking operations. It allows users to create accounts, deposit funds, withdraw money safely with balance checks, view account details, and track real-time transaction updates.

---

## ✨ Features
- **Account Creation**: Set up an account with an initial balance and account holder details.
- **Deposit Operations**: Add money securely with positive value validation.
- **Withdrawal Protection**: Prevents transactions if the withdrawal amount exceeds the available balance (insufficient funds protection).
- **Check Balance & Details**: View real-time balance and account information.
- **Input & Error Handling**: Robust validation against invalid numeric inputs and edge cases.
- **Menu-Driven Interface**: Clean console menu allowing users to perform multiple operations continuously.

---

## 🛠️ Technologies Used
- **Programming Language**: Java (JDK 8 or above)
- **Object-Oriented Programming (OOP)**: Encapsulation, Classes, and Methods
- **Core Libraries**: `java.util.Scanner`
- **Version Control**: Git & GitHub

## ⚙️ How to Setup & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rathodravi5598/CODE_ORBIT_Bank_Account_Simulation.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd CODE_ORBIT_Bank_Account_Simulation
   ```

3. **Compile the Java files:**
   ```bash
   javac *.java
   ```

4. **Run the program:**
   ```bash
   java Main
   ```
   *(નોંધ: જો તમારી મુખ્ય ફાઇલનું નામ અલગ હોય, તો `Main` ની જગ્યાએ તે ફાઇલનું નામ લખવું)*
